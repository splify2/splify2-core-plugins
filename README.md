# splify2/splify2-core-plugins

Официальный репозиторий плагинов splify2, которые ставятся «из коробки»: Andromeda, языки, плагины логики.
Индекс `index.json` и архивы `.s2p` лежат в ветке `gh-pages` и публикуются конвейерами выпуска splify2 и andromeda.
Формат — [splify2/plugin-sdk](https://github.com/splify2/plugin-sdk) (`docs/index.md`).
